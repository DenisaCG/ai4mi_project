# Figure catalog

Every figure produced by the dataset-analysis tooling, what it shows, and
where the idea for it came from. Update this when a figure is added, removed,
or its underlying script changes meaningfully.

Sources referenced below:
- **EDA doc** — the thoracic-CT EDA/QA writeup (coordinate audits, HU ridge
  plots, 3D centroid scatter, spatial occupancy, etc.)
- **planner source** — nnU-Net's own experiment-planning code
  (`determine_fullres_target_spacing`, `crop_to_nonzero`,
  `verify_dataset_integrity`, `CTNormalization`)
- **team** — designed directly for this project, not adapted from an
  external source
