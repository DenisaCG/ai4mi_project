# Fold-0 preprocessing comparison

Four isolated, one-thread registrations of Patient_26 -> Patient_19: native_1/2 and resampled_1/2. Estimation uses native HU or the existing fold-0 pre-crop resampled HU CTs. Every initial, rigid and final transform warps the same native source CT/GT onto the same native target grid. Per-run `reports/qc.json` records all inputs and settings; `summary.json` compares the two repeats. The PNG figures show target and stage-specific warped CT with its own GT contour on the same physical target planes. Stage NIfTIs and verified transforms are under each run's `volumes/` and `reports/`. Final-stage CT/GT are passed through the unchanged production slicer in an isolated temporary directory for ROI retention QC; that temporary data is removed. The real fold's statistics and all production caches remain read-only. Target GT is used only for QC. Body overlap uses a simple CT > -500 HU proxy; CT MAE/RMSE/Pearson use the same target-body mask and [-1000,400] HU window throughout. Deformation Jacobians are sampled on a coarse 4x4x5 mm grid; positive samples do not rule out local folding.
